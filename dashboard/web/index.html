Tracks & GPU

PPO uses a fixed 64-cell ring with ordered gates. Native population training generates seeded closed tracks from game tiles; settings control length, surfaces and doubles. Each generation gets a track from that sequence.

GPU simulation and the policy device are separate choices. Choose rally_gpu.yaml and CUDA for both.

Windows setup: powershell -ExecutionPolicy Bypass -File tools/setup_rl_gpu.ps1 -AllowUnsupportedCompiler
